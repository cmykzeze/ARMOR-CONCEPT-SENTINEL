# Voidwarden Armor (Fabric)
Obtain: kill Wardens (25% chance, edit NUGGET_DROP_CHANCE) -> Voidwarden Nugget.
Craft: 8 nuggets around 1 Dragon's Breath (centre) -> Voidwarden Ingot.
Upgrade: Smithing table = Netherite Upgrade Template + NON-ENCHANTED netherite piece + Voidwarden Ingot.
Stats: +100 durability vs netherite per piece, 4/9/7/4 armor, 4 toughness, 0.15 KB resist.
Full set: permanent Strength I + Fire Resistance. Chestplate: asymmetric animated cape.
Build: edit gradle.properties with versions from https://fabricmc.net/develop, then `gradle build`.
Textures are regenerated by `python3 gen.py` (Pillow) if you want to tweak them.


## Visual and cape upgrade (development branch)

- Reworked the four cape panels into a lightweight damped-spring simulation with per-avatar motion state, bounded time steps, damping, and angular limits.
- Cape response now eases into running posture and body turns instead of snapping between fixed sine-wave poses; a small idle sway remains.
- Expanded the deterministic texture generator with raised plate bevels, recessed seams, reactor detailing, visor accents, shoulder/forearm plating, rivets, and greave inlays.
- CI now generates the upgraded PNG textures before packaging and runs on the upgrade branch and pull requests.

The armor's item identifiers, crafting progression, loot chance, armor stats, and full-set effects are intentionally unchanged.
